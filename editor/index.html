      OUTPUT · 实时预览
      ASTRO CONTENT COLLECTIONS · GITHUB PAGES · 100% STATIC导出文件夹 = 1 篇 .md + photos/ 照片集 + HOW-TO-USE.md
      ▤ 图片集这篇文章的全部照片
      上传到这里的图片会随「导出文件夹」一起打包到 md 同目录的 photos/。 相册照片可在卡片里改相机型号；点「绑定选中文字」会生成 #photo-N 整句索引。封面一张图一个角色：勾「用作封面」后在「对应城市」下拉里选城市＝该城市入口的封面；留空＝不带 ?city= 时的默认封面，也可直接点「设为默认封面」。同一城市只能有一张，选中新的会自动取消旧的；置顶的默认封面图同样能勾选，勾上后会一并加入相册。对应 gallery[].cover / gallery[].city / hero.src。 住宿照片请到 02 住宿 卡片里点「＋ 插入 / 更换图片」，会写进 stays[].image。

      会把 .md 与同目录 photos/ 专用照片文件夹（含三档：缩略图 / 短边 4096px、2–3MB 的预览图 / 原图）一起提交到 content 分支；token 不会写入草稿。离线预览请用「导出文件夹」。
